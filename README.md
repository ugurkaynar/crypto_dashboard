2. Proje Hakkında (Kısa Bir Özet):

"Bu proje, gerçek zamanlı Binance verilerini kullanarak kripto para piyasasını analiz etmenizi ve kendi belirlediğiniz parametrelerle algoritmik stratejiler (Backtest) oluşturmanızı sağlayan, Flutter ile geliştirilmiş bir finansal araçtır."

3. Temel Özellikler (Features):

📊 Canlı Mum Grafikleri: Binance üzerinden anlık çekilen verilerle kesintisiz piyasa takibi.

⚙️ Özelleştirilebilir Backtest Motoru: MA kesişimleri ve Stop-Loss/Take-Profit oranları ile risksiz strateji simülasyonu.

💾 Kalıcı Hafıza (Offline-First): Seçilen varlıkların ve hesaplama ayarlarının cihazda güvenle saklanması.

🏗️ Modüler Mimari: Sürdürülebilir ve genişletilebilir Clean Architecture ve MVVM altyapısı.

4. Kullanılan Teknolojiler (Tech Stack):

Frontend: Flutter, Dart

Mimari: Clean Architecture, MVVM

API & Veri: Binance REST API, http

Yerel Depolama: shared_preferences

Deployment: Vercel
